| ✅   | **P1-B-4** | 实现pack内md内容预览和在线编辑 | 详情页「包内文件」：Markdown 列表可选、GFM 预览，作者可编辑保存并重算 zip / SOUL 摘要；二进制仅路径与大小提示，无预览 |
| ✅   | **P1-C**   | 实现即时chat | 详情页多轮对话；系统与用户侧约定上下文一并注入；登录且仅对可见 pack 开放；与本机 OpenClaw 深度联动解耦，先做站内闭环。 |
| ✅   | **P1-D**   | 直接在web创建 pack | 在用户dashboard 【在本机 workspace 发布】前新增 【从零构建你的 SOUL】，点击之后弹出框输入要创建的 slug 名称，确认后进入新增的pack详情页，用户手动在现有的【包内文件】模块新增文件并编辑（复用编辑逻辑，添加新增文件），及实现其他需要的配套逻辑｜
