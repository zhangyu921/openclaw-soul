# Web i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Parallelization:** Tasks **1–3** (deps + config + middleware), **4** (tree move), and **7** (message merge helper + tests) can be split across subagents after shared interfaces (`routing`, `locales`) land—merge order: finish Task 1 first, then 2–3, then 4, then 5–9.

**Goal:** Add locale-prefixed routing (`/en`, `/zh`) with `next-intl`, `Accept-Language` + **`NEXT_LOCALE` cookie** (priority: cookie > `Accept-Language` > `en`), Chinese-first UI strings for dashboard/login/register/create-pack flows, and repo-editable JSON messages with **zh missing keys falling back to en**.

**Architecture:** Follow [next-intl App Router + routing setup](https://next-intl.dev/docs/routing/setup): `src/i18n/routing.ts` (`defineRouting`), `src/i18n/request.ts` (`getRequestConfig`), `src/i18n/navigation.ts` (`createNavigation`), `messages/*.json`, root `app/layout.tsx` pass-through (see [example](https://github.com/amannn/next-intl/blob/main/examples/example-app-router/src/app/layout.tsx)), real `<html lang>` in `app/[locale]/layout.tsx`. **Next.js 16** deprecates `middleware.ts` → `proxy.ts` for Edge-free Node proxy; **`next-intl` still documents `middleware.ts` + `createMiddleware` (Edge)**—keep **`src/middleware.ts`** so locale negotiation stays supported until `next-intl` documents a `proxy` integration ([Next 16 upgrade: keep `middleware` if you need Edge](https://github.com/vercel/next.js/blob/canary/docs/01-app/02-guides/upgrading/version-16.md)).

**Tech Stack:** `next@16.2.1`, `next-intl` (add to `web/package.json`), existing `pnpm` workspace, `vitest` for small unit tests.

**Spec:** [`docs/superpowers/specs/2026-04-08-web-i18n-design.md`](../../specs/2026-04-08-web-i18n-design.md)

- [ ] **Step 1: 实现合并工具 `web/src/lib/i18n-messages.ts`**

```typescript
export function isPlainObject(v: unknown): v is Record<string, unknown> {
  return typeof v === "object" && v !== null && !Array.isArray(v);
}

export function mergeMessagesWithFallback(
  fallback: Record<string, unknown>,
  primary: Record<string, unknown>
): Record<string, unknown> {
  const out: Record<string, unknown> = { ...fallback };
  for (const key of Object.keys(primary)) {
    const p = primary[key];
    const f = fallback[key];
    if (p === undefined || p === null) {
      continue;
    }
    if (isPlainObject(p) && isPlainObject(f)) {
      out[key] = mergeMessagesWithFallback(f, p);
    } else {
      out[key] = p;
    }
  }
  return out;
}
```

（若 `zh` 某叶节点为 `""`，可视作未翻译并在后续迭代改为回退 en；第一期约定：**缺 key 用 en**，显式 `""` 不强制回退。）

```typescript
import { hasLocale } from "next-intl";
import { getRequestConfig } from "next-intl/server";

import { mergeMessagesWithFallback } from "@/lib/i18n-messages";

import { routing } from "./routing";

export default getRequestConfig(async ({ requestLocale }) => {
  const requested = await requestLocale;
  const locale = hasLocale(routing.locales, requested)
    ? requested
    : routing.defaultLocale;

  const en = (await import(`../../messages/en.json`)).default;
  if (locale === "en") {
    return { locale, messages: en };
  }
  const primary = (await import(`../../messages/${locale}.json`)).default;
  return {
    locale,
    messages: mergeMessagesWithFallback(en, primary),
  };
});
```
