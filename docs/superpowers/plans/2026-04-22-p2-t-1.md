# P2-T-1: 画廊 card 被查看次数 Implementation Plan

> **For agents running /harness-go:** 下一步由 P1.5 或同 tick 的 `harness-execute` 按任务顺序执行；每完成一个 Task 做一次本地 commit。步骤用 `- [ ]` 跟踪。

**Goal:** 为 Pack 持久化站内涵览次数；详情页对非作者访问计数；首页 gallery card 在次数 > 10 时于标题行右侧展示。

**Architecture:** 纯函数判定「是否应计一次阅读」+ Vitest；RSC 中在 pack 已解析后 `increment`；首页查询带回 `profileViewCount` 与 flex 行内 UI。

**Tech Stack:** Prisma 7 + PostgreSQL、Next.js App Router、next-intl、lucide-react `Eye`（可选）、Vitest。

**Task 文档：** [`docs/harness/task-p2-t-1.md`](../../harness/task-p2-t-1.md)

**分歧度：** `high`

**Spec：** [`../specs/2026-04-22-p2-t-1-design.md`](../specs/2026-04-22-p2-t-1-design.md)

```ts

  await prisma.pack.update({
    where: { id: pack.id },
    data: { profileViewCount: { increment: 1 } },
  });

  console.error("pack profileViewCount increment failed", e);
}
```
