# P2-S-1: 详情页 hero apply 复制 + CLI 文案 Implementation Plan

> **For agents running /harness-go:** 下一步由 `harness-execute` 按任务顺序执行；每完成一个 Task 做一次本地 commit。步骤用 `- [ ]` 跟踪。

**Goal:** 在详情首屏头像卡片内提供 apply 命令与一键复制；软化底部 CLI 卡片的用户文案。

**Tech Stack:** Next.js App Router、next-intl、Vitest、lucide-react `Copy` 图标。
