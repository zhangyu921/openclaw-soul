# P2-B：首页信息结构（设计）

**日期**：2026-04-11  
**状态**：已定稿  
**范围**：`web/src/app/[locale]/page.tsx`（首页）— **版式与信息层级**：把「是什么 / 为谁 / 怎么用」从单段正文拆成 **清晰分块**；**不**改画廊数据查询、**不**改 API。

**关联**：

- 路线图：[`docs/ROADMAP.md`](../../ROADMAP.md) **P2-B**。
- 文案语气、Soul 用词、i18n 基础设施见 [`2026-04-10-p2c-site-copy-i18n-design.md`](2026-04-10-p2c-site-copy-i18n-design.md)、[`2026-04-08-web-i18n-design.md`](2026-04-08-web-i18n-design.md) — **本 spec 不重述框架，只约束首页结构与新增/调整文案 key**。
- 站点协作入口：[`web/AGENTS.md`](../../../web/AGENTS.md)。

---

## 1. 目标与成功标准

- **目标**：用户扫一眼首页能分清三段价值（What / Who / How），**不**糊成一段长文；首屏主焦点仍是 Badge + 主标题 + 三块说明，**不**被 CLI 等宽行抢占。
- **成功标准**：窄屏单列、桌面三列并排时三块边界清晰；CLI 示意在价值区之下、画廊之上，视觉层级 **次要**；`en` / `zh` 文案齐全、符合 P2-C 用词。

---

## 2. 已定决策（摘要）

| 维度 | 决策 |
|------|------|
| 价值区版式 | 窄屏 **1 列**；`md` 及以上 **3 列并排**（三块并列）。 |
| CLI 行位置 | **三列价值区下方**、**画廊（或空态）上方** 全宽一条窄带。 |
| CLI 行语义 | **示意**：让用户理解「可通过 CLI apply 部署」；**非**首页复制真实 handle/slug 的场景。 |
| 示意文案形态 | **方案 1**：保留完整占位命令（与现 `applyCommandLine` 一致或等价），并增加一句 **预期管理**（完整可复制的命令以 Soul **详情页**为准）。 |
| 详情页 | 精确命令以详情页 CLI 卡片为真源；**一键复制**按钮若尚未实现，可作为 **独立 follow-up**，**不**作为 P2-B 阻塞项。 |

---

## 3. 页面结构（自上而下）

1. **Hero**：Badge、`heroTitle` — 与现逻辑一致。
2. **价值栅格**：三块，每块 **小标题**（原 `introWhatLabel` / `introWhoLabel` / `introHowLabel`）+ **正文**（对应 `intro*Body`）。实现可用 `Card` 或 `div` + 既有 ring/间距 token，以 **轻量、不抢 H1** 为准。
3. **CLI 窄带**：`text-sm`、`text-muted-foreground`；`<code>` 可再降一级对比度。内容：**一行占位命令** + **新增** `applyStripHint`（或等价 key）说明「选定 Soul 后在详情页复制精确命令」类含义（中英润色，与 P2-C 一致）。
4. **画廊区**：现有瀑布流 / 空态 — **逻辑不变**。

---

## 4. i18n

- 命名空间仍用 **`home`**。
- **新增**：`applyStripHint`（中英）— 承担「示意 ≠ 可复制真实 slug」的预期管理。
- 现有 `introWhatLabel` / `introWhatBody` 等 **可继续沿用**；若实现时映射到数组结构，属实现细节，**不要求**为 spec 单独重构 JSON 形状（以改动最小为准）。

---

## 5. 非目标

- 不改 `middleware`、不改 `/api/*`、不把 UGC 塞进 `messages`。
- 不在本 spec 内要求 **详情页「复制命令」按钮**（可选后续任务）。
- 不要求本阶段 **git commit**（以维护者流程为准）。

---

## 6. 验收（实现阶段）

- [ ] 首页三块在桌面为三列、在窄屏为单列，阅读顺序合理（What → Who → How）。
- [ ] CLI 窄带在三块之下、画廊之上，视觉权重低于主标题与三块标题。
- [ ] `en` / `zh` 含 `applyStripHint`（或 spec 约定名称），无遗漏 key。
- [ ] `pnpm` 在 `web/` 下 **lint / build** 通过（与仓库惯例一致）。
