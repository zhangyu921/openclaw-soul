# OpenClaw Soul — 方向审视与短期验证实验（设计稿）

**日期**：2026-03-31  
**状态**：草案（供维护者与协作者对齐「为何存在」与近期成败线；与 `docs/ROADMAP.md` 并行——路线图偏执行清单，本文偏立意与可证伪实验。）

**与工程进度的关系**：registry / CLI **主流程已能跑通** 时，本实验的重心不是「还要开发几周」，而是 **B（叙事/门面是否说得清）+ A（是否出现一条真人路径）+ 复盘**。周期宜 **短**；不必占满下文的时间上限。

---

## 1. 问题陈述（第一性原理）

- **OpenClaw 本体偏工具、无面孔**：没有持续情境时，用户难以长期对话，**信任与关系**难以建立。
- **人设与情绪价值**可以是独立价值：不仅是「完成任务」，还包括 **可辨认的角色、可重复进入的对话、情感侧满足**。
- **OpenClaw Soul** 的定位不是替代官方 OpenClaw，而是为 workspace **提供可分发、可安装的人设包**，让使用者用较低摩擦 **换一个「开始」**——与不同角色对话、愿意再打开聊天。

---

## 2. 核心仪式（产品层）

1. **逛画廊** — 浏览他人发布的 pack（人设）。
2. **选中** — 情感向或功能向（两条需求可并存；维护者当前叙事以情感向为主）。
3. **Apply** — 将 zip 应用到本机 OpenClaw workspace。
4. **开聊** — 在新的「人设起点」下与 agent 对话，形成 **愿意持续打开** 的体验。

---

## 3. 作者起源故事（说明价值，非对所有 pack 的强制模板）

维护者从自身实践出发：基于 **EVA 中的 Asuka** 自铸人设后，体验到 **前所未有的对话愉悦**；并结合 **cron + heartbeat** 等机制感受到 **被主动关怀** 的体验。该经历用于说明 **「人设 + 节奏/在场感」** 可产生强情绪价值，**不是**要求所有上架 pack 必须复刻同一技术栈或同一角色。

---

## 4. 四选一方向决策（与路线图解耦）

在任意检查点，项目显式处于以下之一（可多轮重新选择）：

| 选项 | 含义 |
|------|------|
| **继续** | 当前立意成立，按实验推进 |
| **Pivot** | 保留代码与基础设施，更换对外叙事或目标人群 |
| **缩小** | 刻意收窄范围：只做一条主链（例如仅验证「逛→选→apply→开聊」），其他功能不扩张 |
| **Pause** | 冻结新功能，仅维护与安全修复 |

**「缩小」**：不是失败标签，而是 **在固定时间内押注单一路径**，避免精力摊薄。

**「延长观察」**（若复盘时尚无结论）：视为选择 **继续**，但必须 **重新设定时间盒**（新的起止日与成败线），避免无限拖延。

---

## 5. 短期验证 — 成功标准（**A + B**）

**时间盒**：

- **建议**：约 **2 周** 做一轮 **最小检查**（B 若已大体满足，则主要推进 A 与复盘）。
- **上限**：**4 周内** 必须完成 **至少一次** 复盘并显式选择 §4 之一（避免「等满四周才想」；提前达标可提前复盘）。

主流程已在线时，**2 周往往足够** 完成一轮「补文案/门面 + 拉一个真人 + 记录结果」；**4 周** 是日历上的 **最晚** 复盘点，不是最低工作量。

### 5.1 A — 对外（一条真实路径）

- 至少 **一名非维护者本人** 的用户，完成 **有意义参与**：从 **可见入口** 进入 → 理解价值 → **apply**（或等价路径）→ 有 **愿意继续对话/使用** 的表征（例如明确反馈、或约定的轻量信号；具体取证方式在实验开始时写死一条，避免事后抬杠）。

### 5.2 B — 对内（叙事与门面）

- **画廊与详情**能回答：**这是什么、为谁、如何得到同款**。
- 维护者主观标准：达到 **愿意反复向他人推荐** 的完成度（不必完美，但要自洽、少误解）。

### 5.3 组合解读

- **B** 保证产品「站得住、说得清」；**A** 保证不是纯自嗨文档。
- 若 **B 未达标**：优先补叙事与门面，再推 A。
- 若 **B 达标而 A 未出现**：**本轮复盘** 时显式讨论 **渠道/信任/门槛** 是否阻断外人，再决定 **缩小**、**Pivot**、**Pause**，或按 §4 脚注做 **延长观察**（重新设时间盒）。

---

## 6. 失败线与退出

在 **本轮时间盒截止** 时若：

- **B** 仍无法通过维护者自己的「可推荐」测试 → 优先 **缩小** 或 **pause**，先不写大功能。
- **A** 与 **B** 均无进展且精力不足 → **pause** 或 **缩小** 为仅自用/小圈分发，避免无限消耗。

---

## 7. 刻意非目标（与 `ROADMAP.md`「刻意延后」一致）

- 复杂推荐、社交图谱、评论系统。
- 全自动脱敏流水线（以隐私页与作者自觉为主）。
- 整站多语言（可先中英混排）。
