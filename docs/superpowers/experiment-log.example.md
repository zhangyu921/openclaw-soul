### 何谓「愿意继续」（维护者须写成一段话，锁定标准）

以下为**常见、可接受的信号类型**（便于对齐，非强制全选；请在下方 `[PLACEHOLDER]` 用**一段话**写死你本次采用的定义）：

- **私聊同意**：对方在 DM 等私域中明确表示愿意继续试用、愿意再聊、或同意你保留一条**匿名化**复盘记录；取证可为**打码截图**（隐去昵称、头像、ID）或**逐字摘录 + 日期**，并注明渠道。
- **公开表征**：公开回复或帖子中可核验的「已 apply / 会继续用」等表述；取证为**可访问链接**（若存在）**加**带日期的截图归档，以防删帖。
- **后续约定**：双方确认的**已排期 follow-up**（通话/再聊）；取证为日历邀请截图、或双方文本中明确时间与会话形式的记录。
